# Programmation web : travaux dirigés

Mes travaux dirigés de **programmation web** en HTML, CSS et JavaScript pur, sans framework.

## Contenu

| Dossier | Sujet | Notions |
|---|---|---|
| [`TD1`](TD1) | Jeu de 52 cartes en HTML et CSS | Structure HTML, Flexbox, rotation (`transform`), couleurs et tailles par classes, dos de carte en `conic-gradient` |
| [`TD2`](TD2) | **Jeu de Blackjack** | JavaScript : DOM, événements, paquet de 52 cartes, valeur de l'as (1 ou 11), mise et solde, croupier |
| [`TD3`](TD3) | **Application météo (Single-Page Application)** | JavaScript : `fetch`, API REST (Open-Meteo), carte interactive (Leaflet), clic sur la carte pour choisir un lieu |

## Les TD les plus complets

- **Blackjack (`TD2`)** : le joueur mise, tire des cartes ou s'arrête, puis le croupier joue. Le solde est mis à jour à chaque partie. Les cartes sont celles créées en HTML/CSS aux TD précédents.
- **Météo (`TD3`)** : on cherche une ville ou on clique sur la carte pour afficher la météo actuelle et les prévisions des jours suivants. Les API utilisées (Open-Meteo, BigDataCloud) ne demandent aucune clé.

## Lancer un TD

Il suffit d'ouvrir le fichier HTML dans un navigateur :

- `TD1/index.html`
- `TD2/bj.html`
- `TD3/index.html` (nécessite une connexion internet)
